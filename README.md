# 国科大选课规划

面向中国科学院大学研究生的本地选课辅助工具。网站不会连接学校账号，也不会代替正式选课系统；培养身份、正式方案、备选池和已修历史默认保存在当前浏览器。

## 主要功能

- 六类学生培养矩阵、每学期 10 学分、2+2、博士课程、公共选修与工程伦理检查
- 硕士英语 A 三种方案，以及博士英语 B 同学期“读写类 + 听说类”组合检查
- 秋春课程目录、虚拟滚动筛选、正式方案、备选池、学位课确认与重修例外
- 按实际教学周、星期和节次检测冲突，并生成周课表
- Excel 工作簿懒加载导入、JSON 备份恢复、Excel 选课单和打印/PDF
- IndexedDB 本机存储、响应式布局与生产环境离线缓存

## 本地运行

```bash
pnpm install
pnpm dev
```

生产校验：

```bash
pnpm test
pnpm build
```

`pnpm data:build` 会从 `data/` 下三张原始工作簿重新生成 `public/data/catalog.json`。当前基线为秋/春开课计划 1,498/1,476 门，秋/春核心专业课 1,025/876 门，秋季详细排课 2,077 个课程班、3,466 条源时间记录。

## 说明

本工具的判断结果均附带计算口径，但最终仍以个人培养方案、导师与培养单位审核意见以及学校正式系统为准。春季详细课表导入前不会推测教师、周次或节次，也不会把春季课程加入时间冲突计算。
